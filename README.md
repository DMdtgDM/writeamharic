# ድርኛ (Diregna) — Build Websites in Amharic

**Start here:** `docs/DIRENYA_DOCUMENTATION.md` — the full design document, language reference, worked examples, teaching curriculum, and honest limitations list.

**To try it right now:** open `playground/index.html` in any browser. No install, no server.

**Project layout:**
- `lib/` — the four transpiler modules + build CLI (Node, but written to also run unmodified in a browser)
- `playground/` — the self-contained live editor kids actually use
- `examples/` — automated tests (all passing) + one full worked student project
- `docs/` — the complete documentation
